# สตาร์ตเตอร์ Lab 11 — แอปส่งอาหารที่รันขึ้นแล้ว แต่ยังไม่ต่อฐานข้อมูล

นี่คือ **สตาร์ตเตอร์** ของ Lab 11 — **แอปส่งอาหาร** 6 จอที่ประกอบไว้ให้แล้ว ประกอบตามขั้นตอนรันข้างล่างแล้วเปิดดูได้ทันที

แอปนี้เป็น **แอปส่งอาหาร ไม่ใช่แอปของร้านใดร้านหนึ่ง** ผู้ใช้เปิดมาเห็นรายชื่อร้านที่ส่งถึงที่อยู่ของตัวเอง เลือกร้าน แล้วจึงเห็นเมนูของร้านนั้น

รายการเมนูที่เห็นบนจอตอนนี้เป็น **รายการตัวอย่างที่เขียนค้างไว้ในโค้ด** ที่ `lib/data/demo_menu.dart` ไม่ได้มาจากฐานข้อมูล · ในโครงนี้ **ยังไม่มีแพ็กเกจของ Firebase อยู่เลย** ไม่มี `firebase_core` ไม่มี `cloud_firestore` และไม่มี `firebase_auth`

- **หน้าแรก** — แถบที่อยู่ปลายทาง ช่องค้นหาร้านหรือประเภทอาหาร แถวร้านแนะนำที่เลื่อนแนวนอน และรายชื่อร้านทั้งหมดที่ส่งถึงที่อยู่นี้ การ์ดละ ประเภทอาหาร อำเภอ คะแนนพร้อมจำนวนรีวิว เวลาส่ง ระยะทาง และป้ายส่งฟรี
- **จอร้าน** — กดร้านแล้วเข้า มีหัวร้าน ช่องค้นหาเมนูในร้านนั้น และรายการเมนูของร้าน · **จอนี้คือจอที่เกี่ยวกับงานข้อ ① และเป็นจอที่ต้องถ่ายภาพส่ง**
- **จอรายละเอียดเมนู** — กดที่การ์ดเมนูแล้วเข้า มีภาพใหญ่ ราคา แถบร้าน ตัวเลือกจำนวน และปุ่มเพิ่มลงตะกร้า
- **จอตะกร้า** — บอกว่าสั่งจากร้านใด รายการพร้อมภาพ ปุ่มเพิ่มลดจำนวน ที่อยู่ปลายทาง ค่าส่ง ยอดที่ต้องจ่ายจริง และปุ่มสั่งและให้ไปส่ง
- **จอออเดอร์ของฉัน** — ออเดอร์ที่สั่งไปแล้วพร้อมสถานะ **รอคนส่งรับงาน**
- **จอเข้าสู่ระบบ** — ช่องอีเมลและรหัสผ่าน พร้อมปุ่มสมัครบัญชีใหม่ ปุ่มเข้าสู่ระบบ และปุ่มออกจากระบบ
- **แถบล่างสี่ปุ่ม** — ร้านอาหาร · ออเดอร์ · ตะกร้า · บัญชี พร้อมป้ายจำนวนชิ้นบนปุ่มตะกร้า

การเดินระหว่างจอต่อไว้ให้ครบแล้ว **ไม่ต้องเขียน router เอง**

**หนึ่งออเดอร์สั่งได้จากร้านเดียว** เพราะคนส่งหนึ่งคนไปรับที่ร้านเดียว ถ้าเลือกร้านใหม่ทั้งที่ยังมีของค้างในตะกร้า แอปจะถามก่อนล้างตะกร้า

งานของคุณในแล็บนี้คือ **เปลี่ยนแหล่งข้อมูลของแอป** และ **เพิ่มการเข้าสู่ระบบ** ไม่ใช่การวาดหน้าจอใหม่

## สภาพปัจจุบัน — สามจุดในโค้ดที่ยังทำงานไม่ได้

**หน้าจอทั้งหมดทำงานได้แล้ว** สิ่งที่ยังไม่ทำงานคือส่วนที่อยู่หลังหน้าจอ · กดปุ่มสั่งหรือปุ่มบนจอเข้าสู่ระบบตอนนี้ จอจะขึ้นข้อความว่า `ยังไม่ได้ทำ — งานข้อ ... ของแล็บ` · **นี่คือจุดตั้งต้นที่ถูกต้องของแล็บนี้ ไม่ใช่ข้อผิดพลาดของโครง**

| จุดที่ต้องเติม | ไฟล์ | สภาพตอนนี้ |
|---|---|---|
| ① เมนูของร้าน | `lib/repositories/menu_repository.dart` | คืนรายการจาก `demo_menu.dart` |
| ② การเข้าสู่ระบบ | `lib/auth_service.dart` | ทั้งสี่ส่วนโยน `UnimplementedError` |
| ③ การสั่ง | `lib/repositories/order_repository.dart` | `placeOrder()` โยน `UnimplementedError` |

ในสามไฟล์นั้น ทุกจุดที่ต้องแก้มีคำว่า **จุดที่ต้องเติม** กำกับไว้ · ค้นคำนี้ในโปรเจคแล้วจะพบครบทุกจุด

## โจทย์ของคุณ — ข้อ ① เมนูของร้านต้องมาจาก Cloud Firestore

> **รายชื่อร้านบนหน้าแรกไม่ใช่งานของแล็บนี้** อยู่ที่ `lib/data/demo_restaurants.dart` และเขียนค้างไว้ในโค้ดให้แล้ว · งานของคุณคือ **เมนูที่อยู่ข้างในร้าน**

- สร้าง Firebase project ในบัญชีของคุณเอง ต่อแอปนี้เข้ากับ project นั้น แล้วเพิ่ม `cloud_firestore` เข้าโปรเจค
- แก้ `loadMenu()` ใน `lib/repositories/menu_repository.dart` ให้คืนรายการเมนูที่อ่านมาจากฐานข้อมูล
- ฟังก์ชันนั้นคือที่เดียวที่จอร้านใช้ดึงข้อมูล จอไม่รู้จักแหล่งข้อมูล จึงไม่ต้องแก้ไฟล์ในโฟลเดอร์ `screens` และ `widgets`
- **วิธีพิสูจน์กับตัวเอง:** แก้ชื่อหรือราคาของเมนูหนึ่งรายการในหน้าคอนโซล แล้วกดเข้าร้านอีกครั้ง สิ่งที่ขึ้นบนจอต้องเปลี่ยนตามค่าในฐานข้อมูล

---

## โจทย์ของคุณ — ข้อ ② สมัครบัญชีและเข้าสู่ระบบจากในแอป

- เติมทั้งสี่ส่วนใน `lib/auth_service.dart` ให้สมัครบัญชีใหม่และเข้าสู่ระบบด้วยอีเมลและรหัสผ่านได้จากในแอป
- บัญชีต้องเกิดจากการสมัครในแอป ไม่ใช่สร้างด้วยมือในหน้าคอนโซล
- ค่าที่ `currentUid` คืนคือ **รหัสประจำตัวผู้ใช้ (uid)** ของบัญชีที่กำลังเข้าสู่ระบบอยู่ · ถ้ายังไม่มีใครเข้าสู่ระบบให้คืน `null`
- จอเข้าสู่ระบบเรียกใช้ทั้งสี่ส่วนนี้ครบแล้ว และแสดงข้อความที่โยนออกมาให้เอง จึงไม่ต้องแก้ไฟล์ของจอ

---

## โจทย์ของคุณ — ข้อ ③ กดสั่งแล้วเอกสารออเดอร์เกิดขึ้นจริง

- เติม `placeOrder()` ใน `lib/repositories/order_repository.dart` ให้เขียนเอกสารออเดอร์ลง Cloud Firestore จริง
- เอกสารนั้นต้องมีฟิลด์ที่เก็บ `uid` ของบัญชีที่กำลังเข้าสู่ระบบอยู่ · **ชื่อฟิลด์และฟิลด์อื่นในเอกสาร คุณเป็นผู้ตัดสินเอง**
- ค่าที่ `order.toMap()` ใน `lib/models/food_order.dart` คืนออกมาเป็นเพียงจุดตั้งต้น แก้ได้ตามที่คุณตัดสินไว้
- จอตะกร้าเรียก `placeOrder()` ครบแล้ว และส่งออเดอร์กับ `uid` เข้ามาให้พร้อม

## สิ่งที่ให้มาแล้ว ไม่ต้องทำเอง

- **หน้าจอทั้งสามจอครบแล้ว** รวมทั้งการแสดงสามสถานะของจอเมนู คือกำลังโหลด ได้ข้อมูล และเกิดข้อผิดพลาด
- **ตะกร้า** (`lib/cart_view_model.dart`) เก็บไว้นอกหน้าจอด้วย `ChangeNotifier` จอวาดใหม่เองเมื่อของในตะกร้าเปลี่ยน
- **รูปข้อมูล** ของเมนูและของออเดอร์ (`lib/models/`) พร้อม `MenuItem.fromMap()` สำหรับข้อมูลที่อ่านมาเป็นรูป Map
- **สีและรูปแบบตัวอักษร** (`lib/theme.dart`) และภาพอาหาร 8 ไฟล์ใน `assets/images/`

## ขั้นตอนรัน

โครงนี้มีเฉพาะโฟลเดอร์ `lib` กับ `assets` และไฟล์ตั้งค่า · **ส่วนของ Android ต้องสร้างเพิ่มด้วยคำสั่งในขั้นที่ 2**

ชื่อโปรเจคที่ Dart ใช้จริงมาจากบรรทัด `name:` ใน `pubspec.yaml` ไม่ได้มาจากชื่อโฟลเดอร์ · จะตั้งชื่อโฟลเดอร์เป็นอย่างอื่นก็ยังรันได้ แต่ขั้นตอนข้างล่างใช้ชื่อ `food_order_lab11` ตลอด

```bash
# 1. รับโครงลงเครื่อง โดยตั้งชื่อโฟลเดอร์ปลายทางในคำสั่งเดียวกันเลย
git clone https://github.com/comdet/cp422021-lab11-food-order food_order_lab11
cd food_order_lab11

# 2. เติมไฟล์ส่วนของ Android เข้ามาในโปรเจคนี้
flutter create --platforms=android .

# 3. ดึงแพ็กเกจตามที่ pubspec.yaml ประกาศไว้
flutter pub get

# 4. เปิดเครื่องจำลองหรือต่ออุปกรณ์ Android ไว้ก่อน แล้วสั่งรัน
flutter run
```

**ถ้าคำสั่งใดแจ้งข้อผิดพลาด ให้เก็บข้อความนั้นไว้เขียนลง `NOTE.md`** แล้วสั่ง AI agent ช่วยอ่าน · ติดนานให้ถามผู้ช่วยสอนภายใน 2 วันแรก
